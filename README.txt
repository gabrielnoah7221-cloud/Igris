SADEEQ SYSTEM — INSTALLABLE PWA

IMPORTANT:
A PWA cannot be installed from a local file:// URL. Chrome needs the files served from HTTPS
(or localhost for testing). Once hosted on any HTTPS static host, open the URL in Chrome and
choose "Install app" / "Add to Home screen".

No paid backend is required. User progress remains in localStorage on the device.
